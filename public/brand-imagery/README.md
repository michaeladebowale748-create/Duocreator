# Duocreator Natural Soft image grade

Three Duocreator project photos are exported as high-quality WebP with a 7,680 px long edge. The `.cube` file beside them is the matching 33-point 3D LUT used for the color grade.

## Look

- Natural, restrained warmth in highlights
- Lifted blacks and soft contrast
- Slightly reduced saturation
- Detail-preserving light noise cleanup and sharpening
- Original composition and depth of field retained

## Reuse

Import `Duocreator-Natural-Soft.cube` into a photo or video editor that supports `.cube` 3D LUTs. Apply it before making exposure or white-balance corrections. The LUT only controls color and tone; it does not denoise, sharpen, resize, or blur an image.
